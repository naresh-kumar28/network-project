What is EPIN?

EPIN (Electronic PIN) is a unique code that can be used by users to join the plan.

How EPIN Works?

  1. Admin generates EPIN for a selected plan.
  2. Each EPIN is a unique code.
  3. Members use EPIN during registration.
  4. System validates and activates the plan.
  5. EPIN can have usage limit and expiry.

Benefits

  • Easy offline sharing
  • Track usage and validity
  • Prevent unauthorized access
  • Support campaigns and events
Note: Once EPIN is used (as per usage limit), it cannot be used again.
